# Спецификация пользовательского интерфейса
## Веб-инструмент генерации изображений через шлюз NordRouter

> **Дизайн:** приоритетный источник визуального стиля — [`design.md`](./design.md).
> Все цвета, типографика, скругления, тени, отступы и компоненты берутся оттуда.
> Данный файл описывает **функционал и поведение**; если здесь есть упоминания
> дизайна, они уступают `design.md`.

---

### 0. Назначение и принципы

Инструмент маркетолога для поточного создания рекламных креативов и любых других изображений через API шлюза NordRouter.

Принципы:
1. **Один запуск — много результатов:** любой промт можно прогнать через несколько моделей и/или несколько вариантов за одно нажатие.
2. **Ничего не теряется:** каждый промт, параметры, референсы и результаты хранятся и доступны завтра и через месяц.
3. **Возврат в один клик:** к любой прошлой генерации можно вернуться и повторить её с изменениями одной кнопкой.
4. **Служебное скрыто:** ключи, фильтры безопасности, адреса API в интерфейсе отсутствуют — они живут в конфиге сервера.
5. **Адаптивность:** полноценная работа с телефона (доступ через интернет из браузера).
6. Язык интерфейса — русский.

### 1. Состав экранов и навигация

| Экран | Назначение |
|---|---|
| Вход | Авторизация по паролю |
| Генерация | Основной рабочий экран: форма + лента результатов |
| История | Все прошлые генерации, поиск, возврат промтов |
| Шаблоны | Заготовки промтов под типовые задачи (баннеры, каталог и т.п.) |

Навигация: вкладки в шапке (Генерация / История / Шаблоны) + кнопка «Выйти». На телефоне — нижняя панель с теми же тремя пунктами.

---

### 2. Экран «Вход»

- Одно поле «Пароль доступа», кнопка «Войти».
- Сообщение об ошибке при неверном пароле. Без регистрации, без восстановления — пароль задаётся в конфиге сервера.

### 3. Экран «Генерация» (основной)

Состоит из двух зон: **панель генерации** (форма) и **лента результатов**.
- Десктоп: форма — фиксированная колонка слева (~360 px), лента справа.
- Телефон: форма сверху сворачиваемым блоком («аккордеон»), лента под ней.

#### 3.1. Панель генерации (элементы сверху вниз)

**3.1.1. Шаблон (необязательно).**
Выпадающий список с поиском по шаблонам (см. экран «Шаблоны»). При выборе: промт заполняется заготовкой, над полем промта появляются поля переменных шаблона, подставляются рекомендованные модели и пропорции. Кнопка «Сбросить шаблон» возвращает пустую форму.

**3.1.2. Промт.**
Многострочное поле с автоувеличением высоты. Плейсхолдер с примером. Комбинация Ctrl+Enter запускает генерацию.

**3.1.3. Референсы (загрузка изображений).**
- Зона загрузки: drag&drop, клик для выбора файлов, на телефоне — выбор из галереи/камеры.
- Загруженные файлы показываются строкой миниатюр; у каждой миниатюры: порядковый номер и кнопка «×» (удалить).
- **Количество не ограничивается интерфейсом.** Ограничения моделей обрабатываются предупреждениями (п. 3.3).

**3.1.4. Модели (мультивыбор).**
Кнопка «Модели: выбрано N» открывает панель со списком:
- список подтягивается со шлюза (актуальный каталог моделей), сгруппирован по семействам, есть поиск;
- у каждой модели: чекбокс, название, метки «принимает референсы» / «только текст»;
- звёздочка «избранное»: избранные модели закрепляются сверху списка;
- выбранные модели видны на кнопке чипами (например: `Flux 2 Pro × Ideogram v3 ×`).

**3.1.5. Вариантов на модель.**
Степпер (счетчик) от 1 до 8: «сколько разных картинок запустить с каждой выбранной модели». Значение 1 + несколько моделей = режим сравнения моделей; одна модель + N = режим вариантов; комбинация тоже работает.

**3.1.6. Пропорции.**
Выпадающий список с микропиктограммами (фигуры прямоугольников соответствующей формы):
- **«Авто»** — первый пункт. Активен только когда прикреплены референсы. Берёт соотношение сторон первого прикреплённого изображения и передаёт его как целевую пропорцию. Если референсов нет — пункт неактивен (greyed out) с подсказкой «прикрепите изображение». Когда выбран и референс есть, рядом показывается вычисленное соотношение (например «Авто (3:4)»).
- `1:1`, `4:5`, `3:4`, `9:16`, `16:9`, `21:9` — фиксированный набор.

Выбранное значение отображается пиктограммой + подписью.

**Как «Авто» работает с моделями:**
- `/media` контур (Nano Banana Pro, Grok, Qwen3 Pro): вычисленное соотношение передаётся как `aspect_ratio`. Если точное значение не совпадает с поддерживаемыми шлюзом — округляется к ближайшему.
- `/v1` контур (GPT Image 2): вычисляется ближайший стандартный `size` из соотношения сторон референса (например 1200×800 → 3:2 → `1536x1024`).
- Если модель не поддерживает произвольные пропорции — молчаливый фолбэк на значение по умолчанию + пометка в подсказке к карточке.

**3.1.7. Разрешение.**
Сегментированный переключатель `1K / 2K / 4K`, по умолчанию 1K.

**3.1.8. Дополнительно (свернутая секция, раскрывается по желанию).**
- Формат файла: `png / jpeg`;
- «Улучшить промт» (модель сама детализирует описание): вкл/выкл, по умолчанию выкл;
- Комментарий/метка генерации (свободный текст для себя, попадает в историю).

**3.1.9. Кнопка «Сгенерировать».**
Крупная, в конце формы. На ней же — расчёт запуска: «2 модели × 3 варианта = 6 изображений». Без промта неактивна. Во время выполнения показывает общий прогресс («готово 4 из 6») и не блокирует просмотр ленты.

#### 3.2. Лента результатов

Хронологическая лента блоков генерации (как в чате: новые снизу, автоскролл к новому блоку).

**Блок генерации** содержит:
- шапку: время, состав запуска («3 модели × 2 варианта», пиктограмма пропорции, метка-комментарий если был);
- сетку карточек результатов;
- под сеткой — **полный текст промта** (сворачивается, если длинный) с кнопкой «Копировать промт»;
- миниатюры прикреплённых референсов (клик — просмотр).

**Карточка результата** (одно изображение):
- жизненный цикл: «в очереди» → «генерация» (скелетон/спиннер + имя модели) → «готово» (превью) либо «ошибка» (текст причины + кнопка «Повторить»);
- превью вписано в карточку; клик по превью — полноэкранный просмотр (зум, листание стрелками между карточками блока, кнопка скачать);
- бейдж модели на карточке;
- кнопки карточки (иконки с подсказками):
  1. **Скачать** — полноразмерный файл без сжатия;
  2. **Открыть в новой вкладке**;
  3. **Копировать промт**;
  4. **Перегенерировать** — подставляет в форму промт, референсы и все параметры именно этой генерации; форма подсвечивается, автозапуск НЕ происходит (пользователь правит и жмёт кнопку сам);
  5. **Повторить** — только для карточек с ошибкой, перезапуск именно этого запроса.

Карточки внутри блока независимы: ошибка одной модели не трогает остальные.

#### 3.3. Правила поведения и краевые случаи

- **Референсов больше, чем поддерживает модель:** перед запуском в форме выводится предупреждение «Модель X принимает до N референсов — ей уйдут первые N». Генерация не блокируется.
- **Модель «только текст», а референсы прикреплены:** предупреждение «Модель X проигнорирует референсы».
- **Пропорция/разрешение не поддерживаются моделью:** молчаливый фолбэк на значение модели по умолчанию + пометка в подсказке к карточке.
- **Все карточки блока упали с ошибкой:** в блоке показывается общая причина и кнопка «Повторить все».
- **Перезагрузка страницы во время генерации:** блоки восстанавливаются со статусами «генерация», результаты доподгружаются по готовности (задачи живёт на сервере, не в браузере).
- **Имя скачиваемого файла:** `ГГГГ-ММ-ДД_модель_вN.png` (например `2026-10-27_flux2-pro_v2.png`).
- **Всё пишется в историю сразу**, включая неудачные попытки с текстом ошибки.
- **Тост-уведомления** для действий: «Промт скопирован», «Сохранено», ошибки.

### 4. Экран «История»

- Каждая запись отображается как карточка с **сеткой изображений 4 колонки** (на мобильных — 2 колонки). Изображения крупные, достаточно для чтения текста на баннерах.
- Под сеткой: промт (до 2 строк с обрезкой), мета-информация (дата, количество моделей, статус, комментарий).
- Кнопки записи: «Копировать промт», «Перегенерировать» (загружает параметры в форму), «Удалить».
- Клик по изображению открывает лайтбокс со всеми готовыми изображениями этой записи.
- Фильтры: текстовый поиск по промту, фильтр по моделям (мульти), фильтр по периоду.
- MVP-персистентность: метаданные хранятся в `web/storage/state.json`, изображения — файлами в `web/storage/images/`. При перезапуске сервера незавершённые генерации помечаются как ошибка «Прервано перезапуском сервера».

---

### 5. Экран «Шаблоны»

- Сетка карточек шаблонов: иконка, название, категория («Fashion», «Баннеры», «Карточки маркетплейсов», …), краткое описание.
- Действия с карточкой: «Использовать», «Редактировать», «Дублировать», «Удалить».
- **«Использовать»:** открывает экран «Генерация», промт заполнен скелетоном, над промтом появились поля переменных (каждое со своей подписью и примером), подставлены рекомендованные модели/пропорции шаблона. Переменные подставляются в промт при запуске.
- **Редактор шаблона:** название, категория, описание, скелет промта с плейсхолдерами переменных в фигурных скобках, список переменных (имя, подпись, пример), рекомендованные модели (чекбоксы из общего списка), пропорции и разрешение по умолчанию.
- **Предустановленные шаблоны при первом запуске:**
  1. «Каталожная съёмка белья» (рекомендованные модели: Flux 2 Pro, Ideogram v3, Seedream);
  2. «Баннер Яндекс.Директ: товар + текст» с переменной «стиль» (яркий / сдержанный / с кнопкой);
  3. «Флэтлей товара»;
  4. «Карточка товара для маркетплейса».

### 6. Сводная таблица параметров формы

| Параметр | Элемент управления | Значения | Источник значений |
|---|---|---|---|
| Шаблон + переменные | выпадающий список + текстовые поля | любые | база шаблонов |
| Промт | textarea | свободный текст | пользователь |
| Референсы | мульти-загрузка миниатюрами | изображения, без лимита количества | пользователь |
| Модели | чекбокс-список с поиском и избранным | любые image-модели шлюза | API шлюза (каталог моделей) |
| Вариантов на модель | степпер | 1–8 | пользователь |
| Пропорции | выпадающий список с пиктограммами | Авто, 1:1, 4:5, 3:4, 9:16, 16:9, 21:9 | Авто — из референса; остальные — фиксированный набор |
| Разрешение | сегмент-переключатель | 1K / 2K / 4K | фиксированный набор |
| Формат файла | переключатель (в «Дополнительно») | png / jpeg | фиксированный набор |
| Улучшить промт | тумблер (в «Дополнительно») | вкл / выкл | пользователь |
| Комментарий | текстовое поле (в «Дополнительно») | свободный текст | пользователь |

**Сознательно отсутствует в интерфейсе:** тумблер фильтра 18+ (всегда берётся из конфига сервера), API-ключ и адрес шлюза, управление ценами, регистрация пользователей и роли.

### 7. Контрольные сценарии (чек-лист приёмки)

1. **Пачка креативов:** промт + 3 референса + 3 модели × 2 варианта + 16:9 → запуск → 6 карточек параллельно показывают «генерация» → превью появляются по готовности → два файла скачаны в полном размере, промт третьей карточки скопирован.
2. **Итерация:** под понравившейся карточкой «Перегенерировать» → форма заполнилась промтом, референсами и параметрами → промт правится → запуск → новый блок в ленте, старый не тронут.
3. **Возврат через время:** завтра открыта «История», поиск по слову из промта → запись открыта → промт скопирован / генерация повторена.
4. **Шаблон:** «Шаблоны» → «Баннер Яндекс.Директ» → переменные: товар, текст выгоды, стиль = «с кнопкой» → запуск на рекомендованных моделях.
5. **Телефон:** тот же путь целиком: форма-аккордеон, загрузка из галереи, карточки в одну колонку, полноэкранный просмотр листанием.
6. **Отказ модели:** одна модель вернула ошибку → её карточка с причиной и кнопкой «Повторить», остальные карточки блока готовы и работают.
7. **Авто-пропорции:** прикреплено изображение 1200×800 → выбрано «Авто» → отображается «Авто (3:2)» → запуск → результат в пропорции 3:2.

### 8. Архитектура и технологический стек

**Фронтенд:** Vanilla HTML/CSS/JS (без фреймворков, без сборки).
**Бэкенд:** FastAPI + Uvicorn (Python, async-native).
**База данных:** SQLite (через aiosqlite) — история, шаблоны, избранное.
**Хранение файлов:** локальная файловая система (`web/storage/images/`, `web/storage/thumbs/`).
**Ядро:** бэкенд импортирует `utils/api_client.py`, `utils/model_families.py` и т.д. напрямую — никакой дублировки логики API.

```
Фронтенд (JS)  ──HTTP──▶  web/backend/app.py  ──import──▶  utils/api_client.py  ──HTTP──▶  NordRouter API
                          (авторизация,                     (готовое ядро,
                           SQLite, файлы,                    не трогаем)
                           задачи)
```

**Шрифты:** Inter + JetBrains Mono (Google Fonts CDN или локальные файлы).
**Иконки:** Lucide Icons (SVG inline или CDN) — линейные, outlined, по design.md.
