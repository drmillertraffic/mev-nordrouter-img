# Design System — Dark Dashboard Skin

Универсальное описание дизайн-системы для применения в качестве визуального скина на любую веб-страницу. Основано на тёмной дашборд-эстетике с минимализмом, глубиной через тени и акцентными цветами.

---

## 2. Типографика

### 2.1 Шрифтовые семейства

```css
--font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-mono: 'JetBrains Mono', 'Fira Code', monospace;
```

Основной шрифт — **Inter** (или аналогичный геометрический гротеск). Чистый, нейтральный, отлично читаемый на тёмном фоне. Для кода и технических данных — моноширинный шрифт.

### 2.2 Шкала размеров

| Уровень | Размер | Line-height | Weight | Применение |
|---------|--------|-------------|--------|------------|
| `display` | 32–36px | 1.2 | 700 | Крупные числовые показатели, hero-заголовки |
| `h1` | 24–28px | 1.3 | 600 | Заголовки страниц |
| `h2` | 18–20px | 1.4 | 600 | Заголовки секций, карточек |
| `h3` | 15–16px | 1.4 | 500 | Подзаголовки, названия групп |
| `body` | 14px | 1.5 | 400 | Основной текст |
| `small` | 12–13px | 1.5 | 400 | Подписи, метки, вспомогательный текст |
| `caption` | 11px | 1.4 | 400 | Микротекст, бейджи, тултипы |

## 3. Формы и скругления

### 3.1 Радиусы скругления

| Токен | Значение | Применение |
|-------|----------|------------|
| `--radius-sm` | 6px | Маленькие элементы: бейджи, теги, чипы |
| `--radius-md` | 10–12px | Карточки, панели, контейнеры |
| `--radius-lg` | 14–16px | Крупные блоки, модальные окна |
| `--radius-full` | 9999px | Кнопки-пилюли, аватары, индикаторы статуса |

### 3.2 Принципы форм

- Все контейнерные элементы (карточки, панели, сайдбар) имеют **мягкое скругление** 10–12px
- Кнопки — либо pill-форма (`--radius-full`), либо мягкий прямоугольник (`--radius-sm`)
- Поля ввода — скругление 8–10px, совпадающее с карточками
- Никаких острых углов — весь интерфейс «мягкий»
- Скругления пропорциональны размеру элемента: чем больше блок, тем больше радиус

## 4. Тени и глубина

### 4.1 Система теней

```css
/* Уровень 0 — плоские элементы на фоне */
--shadow-none: none;

/* Уровень 1 — карточки, панели (лёгкое отделение от фона) */
--shadow-sm: 0 1px 3px rgba(0, 0, 0, 0.3), 0 1px 2px rgba(0, 0, 0, 0.2);

/* Уровень 2 — приподнятые элементы (dropdown, popover) */
--shadow-md: 0 4px 12px rgba(0, 0, 0, 0.4), 0 2px 4px rgba(0, 0, 0, 0.3);

/* Уровень 3 — модальные окна, оверлеи */
--shadow-lg: 0 12px 40px rgba(0, 0, 0, 0.5), 0 4px 12px rgba(0, 0, 0, 0.3);

/* Внутренняя тень для инпутов */
--shadow-inset: inset 0 1px 3px rgba(0, 0, 0, 0.3);
```

### 4.2 Принципы глубины

- Глубина создаётся **преимущественно через разницу фоновых цветов**, а не через тени
- Тени используются минимально — только для отделения всплывающих элементов
- Карточки отделяются от фона за счёт того, что `--bg-card` светлее `--bg-surface` на 1–2 ступени
- При hover карточка может слегка «приподниматься»: увеличение тени + сдвиг `translateY(-1px)`
- Никаких ярких свечений (glow) — только мягкие тёмные тени
- Границы (`border`) используются как альтернатива теням для разделения элементов одного уровня

## 5. Отступы и spacing

### 5.1 Базовая единица

Базовая единица — **4px**. Все отступы кратны 4.

### 5.2 Шкала отступов

| Токен | Значение | Применение |
|-------|----------|------------|
| `--space-1` | 4px | Минимальный отступ, gap между иконкой и текстом |
| `--space-2` | 8px | Отступ внутри компактных элементов (теги, бейджи) |
| `--space-3` | 12px | Padding внутри кнопок, инпутов |
| `--space-4` | 16px | Стандартный padding карточек, gap между элементами |
| `--space-5` | 20px | Отступ между секциями внутри контейнера |
| `--space-6` | 24px | Padding крупных панелей, gap между карточками |
| `--space-8` | 32px | Отступ между крупными блоками/секциями |
| `--space-10` | 40px | Отступы на уровне страницы |

### 5.3 Принципы spacing

- **Внутри карточки**: padding 16–24px, gap между внутренними элементами 8–12px
- **Между карточками в сетке**: gap 16–20px
- **Между секциями страницы**: 24–32px
- **Padding страницы**: 24–32px по краям
- **Сайдбар**: ширина 240–280px, padding элементов меню 12px вертикально, 16px горизонтально
- Расстояния создают ощущение «воздуха» — элементы не прижаты друг к другу, но и не разнесены чрезмерно

## 6. Компоненты

### 6.1 Карточки / Панели

```
Фон: --bg-card
Скругление: --radius-md (10–12px)
Граница: 1px solid --border-subtle (опционально, для дополнительного разделения)
Тень: --shadow-sm или отсутствует (разделение через цвет фона)
Padding: 16–24px
```

Карточки — основной строительный блок. Они чуть светлее фона поверхности, что создаёт естественную глубину без теней.

### 6.2 Кнопки

**Primary (основная):**
```
Фон: --accent-white или --accent-green
Текст: --text-inverse
Скругление: --radius-sm (6px) или --radius-full (pill)
Padding: 10px 20px
Font-weight: 500
Hover: лёгкое затемнение фона на 10%
```

**Secondary (вторичная):**
```
Фон: --bg-elevated
Текст: --text-primary
Граница: 1px solid --border-default
Скругление: --radius-sm
Hover: фон --bg-hover
```

**Ghost (прозрачная):**
```
Фон: transparent
Текст: --text-secondary
Hover: фон --bg-hover, текст --text-primary
```

**Icon-only:**
```
Размер: 32×32px или 36×36px
Скругление: --radius-sm или --radius-full
Фон: transparent → --bg-hover при наведении
```

### 6.3 Поля ввода (Inputs)

```
Фон: --bg-input
Граница: 1px solid --border-default
Скругление: 8–10px
Padding: 10px 14px
Текст: --text-primary
Placeholder: --text-muted
Focus: граница --border-focus, лёгкая тень --shadow-inset исчезает
Высота: 38–42px
```

### 6.4 Навигация / Сайдбар

```
Фон: --bg-surface (или --bg-root для максимального контраста)
Ширина: 240–280px
Пункты меню:
  - Padding: 10px 16px
  - Скругление: --radius-sm (8px)
  - Иконка + текст, gap 10–12px
  - Цвет текста: --text-secondary
  - Hover: фон --bg-hover, текст --text-primary
  - Active: фон --bg-active, текст --text-primary, font-weight 500
Разделители секций: лейбл секции в --text-muted, uppercase, 11px, letter-spacing +0.05em
```

### 6.5 Табы / Переключатели

**Pill-стиль (как на скриншоте):**
```
Контейнер: фон --bg-elevated, скругление --radius-full, padding 3–4px
Активный таб: фон --accent-white, текст --text-inverse, скругление --radius-full
Неактивный таб: фон transparent, текст --text-secondary
Анимация переключения: плавный transition 200ms
```

**Underline-стиль (альтернатива):**
```
Активный таб: текст --text-primary, нижняя граница 2px solid --text-primary
Неактивный: текст --text-secondary, без границы
```

### 6.6 Бейджи / Теги / Чипы

```
Фон: полупрозрачный акцентный цвет (например, rgba(52, 211, 153, 0.15) для зелёного)
Текст: соответствующий акцентный цвет
Скругление: --radius-full
Padding: 2px 8px
Font-size: 11–12px
Font-weight: 500
```

### 6.7 Индикаторы статуса

```
Точка статуса: 8px круг, --accent-green / --accent-red / --text-muted
Пульсация (опционально): анимация opacity для online-статуса
```

### 6.8 Тултипы / Popover

```
Фон: --bg-elevated
Граница: 1px solid --border-subtle
Тень: --shadow-md
Скругление: --radius-sm
Padding: 8px 12px
Font-size: 12–13px
```

### 6.9 Dropdown / Select

```
Фон: --bg-card
Граница: 1px solid --border-default
Тень: --shadow-md
Скругление: --radius-md
Пункты:
  - Padding: 8px 12px
  - Hover: --bg-hover
  - Selected: --bg-active
  - Иконка-галочка для выбранного пункта
Стрелка раскрытия: маленькая chevron-иконка, --text-muted
```

### 6.10 Скроллбар

```
Ширина: 6–8px
Track: transparent
Thumb: --bg-elevated, скругление --radius-full
Hover thumb: --text-muted
```

### 6.11 Разделительные линии

```
Цвет: --border-subtle
Толщина: 1px
Стиль: solid
Используются между секциями внутри одной панели, не между карточками
```

### 6.12 Аватары

```
Форма: круг (--radius-full)
Размеры: 28px (small), 32px (medium), 40px (large)
Граница: 2px solid --bg-surface (для отделения от фона)
Fallback: инициалы на фоне --bg-elevated, текст --text-secondary
```

## 7. Графики и визуализация данных

### 7.1 Общие принципы

- Фон графика: прозрачный или `--bg-card`
- Линии сетки: `--border-subtle`, пунктирные или сплошные, очень тонкие (0.5–1px)
- Текст осей: `--text-muted`, 11–12px
- Основные линии/бары: `--text-primary` или `--accent-white` с вариациями opacity
- Градиентная заливка под линией: от `rgba(255,255,255,0.1)` до `transparent`
- Точка на графике: белый кружок 6–8px с тёмной обводкой
- Тултип на графике: стиль как у обычного тултипа (6.8)

### 7.2 Цветовое кодирование

- Позитивная динамика: `--accent-green`
- Негативная динамика: `--accent-red`
- Нейтральные данные: оттенки серого от `--text-muted` до `--text-primary`
- Категории: использовать градации серого + один акцентный цвет для выделения

## 8. Анимации и переходы

### 8.1 Timing

```css
--transition-fast: 150ms ease;
--transition-base: 200ms ease;
--transition-slow: 300ms ease;
```

### 8.2 Что анимируется

- **Hover на кнопках/карточках**: изменение фона, `--transition-fast`
- **Hover на карточках**: лёгкий подъём `translateY(-1px)` + усиление тени, `--transition-base`
- **Переключение табов**: плавное перемещение фона активного таба, `--transition-base`
- **Появление dropdown/tooltip**: fade-in + лёгкий сдвиг вниз, `--transition-fast`
- **Фокус на инпуте**: плавное изменение цвета границы, `--transition-fast`
- **Загрузка**: skeleton-анимация с мерцанием (shimmer) от `--bg-elevated` до `--bg-hover`

### 8.3 Принципы

- Все анимации **быстрые и ненавязчивые** — интерфейс чувствует отзывчивым, не «игрушечным»
- Никаких bounce, elastic, overshoot — только ease/ease-out
- При reduced-motion предпочтения пользователя — отключать трансформации, оставлять только opacity

## 9. Иконки

### 9.1 Стиль

- **Линейные (outlined)** иконки, не заполненные
- Толщина линии: 1.5–2px
- Размер: 16–20px в навигации, 14–16px inline с текстом
- Цвет: наследует цвет текста (`currentColor`)
- Стиль: минималистичный, геометрический (рекомендуется Lucide, Phosphor, Heroicons outline)

### 9.2 Использование

- В навигации: иконка слева от текста, gap 10–12px
- В кнопках: иконка может быть единственным содержимым (icon-only) или слева от текста
- Inline с текстом: размер совпадает с line-height текста
- Акцентные иконки: используют акцентный цвет вместо currentColor


---

## 10. Layout-принципы

### 10.1 Общая структура

- Максимальная ширина контента: не ограничена жёстко, адаптивная
- Сетка: CSS Grid или Flexbox, gap 16–24px между колонками
- Карточки в сетке: равная высота в ряду, auto-fit/minmax для адаптивности
- Мобильная адаптация: одноколоночный layout, сайдбар скрывается в drawer

### 10.2 Визуальная иерархия

1. **Фон страницы** (`--bg-root`) — самый тёмный слой
2. **Поверхности** (`--bg-surface`) — сайдбар, хедер
3. **Карточки** (`--bg-card`) — основной контент
4. **Приподнятые элементы** (`--bg-elevated`) — dropdown, tooltip, active states
5. **Акценты** — зелёный/красный/белый для привлечения внимания

### 10.3 Контраст и читаемость

- Минимальный контраст текст/фон: WCAG AA (4.5:1 для body, 3:1 для крупного текста)
- `--text-primary` на `--bg-card`: ~13:1 ✓
- `--text-secondary` на `--bg-card`: ~7:1 ✓
- `--text-muted` на `--bg-card`: ~4:1 — допустимо только для некритичного текста

## 12. Общий характер дизайна

### 12.1 Атмосфера

- **Тёмный, спокойный, профессиональный** — не агрессивный, не «геймерский»
- **Минималистичный** — каждый элемент на своём месте, нет декоративного шума
- **Глубина через тонкие градации** — 5–6 оттенков тёмного создают многослойность
- **Акценты точечные** — зелёный и красный используются только для смысловых индикаторов, не для декора
- **Мягкость форм** — скругления везде, никаких острых углов
- **Воздух** — щедрые отступы, элементы дышат

### 12.2 Чего избегать

- Ярких насыщенных цветов (кроме точечных акцентов)
- Жёстких теней с большим blur
- Gradient-ов на фонах (только на графиках)
- Декоративных элементов без функции
- Толстых границ (> 1px)
- Sharp corners (border-radius: 0)
- Мигающих/пульсирующих анимаций (кроме статус-индикаторов)
